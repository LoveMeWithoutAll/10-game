# 숫자 10 과일 상자 게임 설계

## 목표

후르츠 박스의 핵심 규칙을 모바일 화면에 맞춘 1인용 브라우저 게임을 React SPA로 만든다. 플레이어는 120초 동안 8×12 보드에서 직사각형을 드래그해 합이 10인 숫자를 제거하고, 제거한 숫자 하나당 1점을 얻는다.

## 확정된 범위

- React와 TypeScript를 사용하는 단일 페이지 애플리케이션이다.
- 별도 서버, 로그인, 데이터 저장, 최고 점수 저장은 구현하지 않는다.
- 보드는 게임을 시작할 때 1부터 9 사이의 숫자 96개를 독립적으로 무작위 생성한다.
- 생성된 보드의 완전 제거 가능성은 보장하지 않는다.
- 사용자가 `게임 시작` 버튼을 누를 때 보드가 생성되고 120초 타이머가 시작된다.
- 마우스, 트랙패드, 터치 입력을 하나의 Pointer Events 흐름으로 지원한다.
- 힌트, 일시 정지, 사운드, 색상 모드, 난이도 선택은 초기 버전에서 제외한다.

## 게임 규칙

1. 보드는 8열, 12행이며 각 칸에는 1부터 9 사이 숫자가 적힌 사과가 하나 있다.
2. 진행 중인 게임에서 포인터를 누르고 이동하면 시작 칸과 현재 칸을 양 끝으로 하는 축 정렬 직사각형이 선택된다.
3. 선택 영역 안의 제거되지 않은 모든 숫자를 더한다. 제거된 빈 칸은 0으로 취급한다.
4. 선택 합계가 정확히 10일 때 선택 테두리를 빨간색으로 표시한다.
5. 합계가 10인 상태에서 포인터를 놓으면 영역 안의 남은 사과를 모두 제거하고, 제거한 개수만큼 점수를 더한다.
6. 합계가 10이 아니면 포인터를 놓아도 보드와 점수는 바뀌지 않는다.
7. 120초가 지나면 입력을 막고 최종 점수를 표시한다.
8. 모든 사과를 제거하면 즉시 게임을 끝내고 최종 점수를 표시한다.
9. `다시 시작`은 새 무작위 보드와 120초 타이머로 즉시 새 게임을 시작한다.

## 상태와 데이터 흐름

게임 상태는 `idle`, `playing`, `finished` 세 단계다. 보드는 `Array<number | null>`로 표현하고, 인덱스는 `row * 8 + column`이다. 드래그 선택은 시작 좌표와 현재 좌표만 상태로 보관하며 직사각형 범위, 선택 합계, 선택 개수는 파생 값으로 계산한다.

`startGame`은 새 보드, 0점, 종료 시각을 동시에 설정한다. 타이머는 고정된 종료 시각과 현재 시각의 차이를 사용해 남은 시간을 계산하므로 백그라운드 탭에서도 실제 경과 시간이 반영된다. 선택 완료는 순수 게임 엔진에 현재 보드와 사각형을 전달하고, 유효할 때만 새 보드와 제거 개수를 상태에 반영한다.

## 구성 요소

- `src/game/gameEngine.ts`: 보드 생성, 사각형 정규화, 선택 인덱스 계산, 합계 계산, 유효 선택 제거를 담당하는 순수 함수.
- `src/game/useFruitBoxGame.ts`: 게임 단계, 보드, 점수, 남은 시간, 시작·재시작·선택 완료를 관리하는 훅.
- `src/components/GameBoard.tsx`: 96개 셀, 포인터 좌표 변환, 선택 프레임과 실시간 합계를 렌더링한다.
- `src/components/GameStatus.tsx`: 점수와 남은 시간을 표시한다.
- `src/components/GameOverlay.tsx`: 시작 전 안내와 종료 결과 및 시작 동작을 제공한다.
- `src/App.tsx`: 게임 상태와 화면 구성 요소를 연결한다.

## 포인터 상호작용

보드는 `pointerdown`에서 포인터를 캡처한다. 보드의 실제 경계와 포인터 좌표를 이용해 열과 행을 계산하고 0~16열, 0~9행으로 제한한다. `pointermove`는 같은 포인터의 현재 칸을 갱신한다. `pointerup`과 `pointercancel`은 선택을 끝내며, 취소 시에는 제거하지 않는다. `touch-action: none`을 보드에 적용해 드래그 도중 페이지 스크롤과 브라우저 제스처가 선택을 방해하지 않게 한다.

## 화면 디자인

대상은 짧은 시간 동안 빠르게 암산하고 싶은 모바일·데스크톱 사용자이며, 화면의 단일 작업은 보드에서 합계 10을 빠르게 찾는 것이다.

- 색상: `Orchard #183F2D`, `Leaf #3F7D43`, `Meadow #9FC45A`, `Board #FFF3C4`, `Apple #E65342`, `Ripe #FFD45A`.
- 글꼴: 제목은 `Arial Rounded MT Bold`, 본문은 `Trebuchet MS`, 점수·시간은 `SFMono-Regular` 계열을 사용한다. 외부 폰트 다운로드는 하지 않는다.
- 레이아웃: 상단에 작은 제목과 상태 패널, 중앙에 모바일 화면 폭에 맞는 8×12 세로형 보드, 하단에 한 줄 규칙 안내를 둔다.
- 대표 요소: 숫자 셀을 납작한 카드 대신 줄기와 잎이 달린 CSS 사과로 표현한다. 선택 영역은 보드 위의 하나의 연속 프레임으로 보여 원작의 드래그 감각을 유지한다.
- 모션: 유효 선택 제거 시 사과가 짧게 축소되며, `prefers-reduced-motion`에서는 전환을 끈다.
- 반응형: 보드는 `aspect-ratio: 8 / 12`와 최대 너비 32rem을 유지하며 모바일에서는 화면 너비를 사용한다. 전체 페이지는 세로 화면에서 한 뷰포트 안에 주요 조작이 들어오도록 구성한다.

## 접근성과 오류 처리

- 시작과 다시 시작은 실제 `button` 요소로 제공하고 키보드 포커스를 명확히 표시한다.
- 보드에는 행·열과 게임 목적을 설명하는 접근 가능한 이름을 제공한다.
- 각 사과는 숫자와 위치를 접근 가능한 이름으로 제공하며 제거된 칸은 비활성 상태로 표현한다.
- 게임이 진행 중이 아닐 때 보드 입력을 무시한다.
- 포인터가 보드 밖으로 나가거나 취소돼도 선택 상태를 정리한다.
- 남은 시간은 화면에는 1초 단위로 표시하되 상태 영역이 과도하게 반복 낭독되지 않게 한다.

## 테스트 전략

- Vitest 단위 테스트로 보드 크기와 값 범위, 역방향 드래그 정규화, 빈 칸을 포함한 합계, 유효·무효 제거, 점수용 제거 개수를 검증한다.
- Testing Library 통합 테스트로 시작 전 상태, 시작 버튼에 따른 게임 전환, 시간 만료, 다시 시작을 검증한다.
- 실제 Chromium 브라우저에서 마우스 드래그로 합계 10 선택, 점수 증가, 반응형 레이아웃과 터치 크기를 확인한다.
- `npm test`, `npm run lint`, `npm run build`를 최종 검증 명령으로 사용한다.

## 완료 기준

- 새로고침 후 저장된 상태 없이 시작 화면이 표시된다.
- 시작 버튼을 누르기 전에는 타이머가 흐르지 않고 보드를 미리 볼 수 없다.
- 시작 후 8×12 무작위 보드와 120초 타이머가 표시된다.
- 어느 방향으로 드래그해도 같은 직사각형이 선택된다.
- 선택 합계가 10인 경우에만 사과가 제거되고 정확한 점수가 오른다.
- 시간 만료 또는 96점 달성 시 추가 선택이 불가능하며 결과가 표시된다.
- 모바일과 데스크톱에서 보드가 가로로 잘리지 않고 조작 가능하다.
